# PriceTruth (MVP)

**Where is your everyday product really cheapest?** — exact branded products compared across Dutch supermarkets, drugstores and discounters, with shelf price, promotion, loyalty-card conditions, price per unit and the freshness/confidence of every observation.

Built with Next.js 14 + Tailwind, data pipeline in Python. See `CLAUDE.md` for architecture and next steps and `docs/01-stage0-testkit.md` for the four-week field test.

## Run locally
```bash
npm install
npm run dev      # http://localhost:3000  (predev decodes data/*.gz.b64 parts)
```

## Data
`data/*.json.gz.b64.partNN` are generated by `scripts/pipeline/build_data.py` from Checkjebon open data (MIT), ah.nl product pages, action.com category pages and Kruidvat/Etos weekly-flyer offers (all read on 15 Aug 2026). See `/data` in the app for freshness per chain.

## Scout reports
`POST /api/observations` stores reports in a GitHub repo when `OBS_GITHUB_TOKEN` and `OBS_GITHUB_REPO` (owner/name) are set; otherwise the app runs in demo mode (reports stay in the browser).

## Disclaimer
Independent MVP, not affiliated with any retailer. Prices are chain-level observations with date and confidence; your local store may differ.
